# 決めた瞬間はいつ？（kimeta-shunkan）

1周2.56秒で回る点の時計を見て、好きなときにボタンを押す。押そうと思った瞬間（W）か押した瞬間（M）の点の位置を答えると、押した時との差がミリ秒で出る。リベットの実験（Libet ほか 1983年）を体験する1日5回のゲーム。2段目は、実験の読み方の問い。

遊ぶ: <https://satou-aaaaa.github.io/kimeta-shunkan/>

- 時計と数字は Libet, Gleason, Wright, Pearl (1983) Brain 106:623-642 <https://doi.org/10.1093/brain/106.3.623> から。読み方が分かれていることは Schurger, Sitt, Dehaene (2012) PNAS 109:E2904 <https://doi.org/10.1073/pnas.1210467109> から。
- 準備電位は脳波なので、このゲームでは測れません。画面の準備電位は論文の数字です。結果の読み方は研究者のあいだで分かれていて、このゲームは「自由意志がある・無い」を決めるものではありません。
- 押した時刻と答えは遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と問いの○×の並び（測った差は入らない）が、選んだサービス（X・LINE など）に渡ります。
